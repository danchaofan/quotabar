额度看板 1.0.3

运行
双击同目录的「额度看板.app」。软件只显示在屏幕顶部菜单栏，不显示 Dock 图标。
点击菜单栏柱状图图标打开面板；点击面板外自动收起。右键图标可刷新、设置或退出。
可将 app 拖入「应用程序」后，在设置中开启开机启动。

剩余额度
Codex：周额度。
智谱 Coding Plan：5 小时、周额度，优先使用接口返回的精确剩余积分。
Kimi Code：5 小时、会员共享月额度。
数字显示剩余百分比，进度条显示已用比例。例如剩余 92% 时，进度条填充 8%。
自动刷新默认每 5 分钟，失败时退避重试。保留上次结果并标注更新时间，超过 15 分钟标记过期。
后台轮询不是实时推送；重置倒计时到零仍需查询确认，不能直接假定恢复为 100%。

账号连接
默认复用当前用户的 Codex CLI、ZCode、Kimi Code 已有登录。
Codex 使用官方 app-server 的 account/rateLimits/read。需要安装并登录 Codex CLI。
智谱使用 ZCode 本机 Coding Plan 配置；也可在设置中输入 Coding Plan API Key，保存到 macOS 钥匙串。
Kimi 优先查询已有的本地桌面/CLI 服务；没有可用服务时会临时启动官方 Kimi CLI 的 loopback 服务，查询后关闭。需要已安装并登录 Kimi CLI。
密钥不写入源码、诊断报告、每日统计缓存或导出文件。不会自动购买额度或发送模型请求。

每日用量
每分钟检查本机记录；首次启动会回填现存的最近 30 天数据。
支持日期切换、最近 7 天趋势、按服务/来源查看、导出 CSV。
输入 token 包含缓存，输出 token 包含服务已归入输出的推理 token。
总 token = 输入（含缓存读取/写入）+ 输出；缓存和推理子项不再次相加。
这不是积分扣费表，各平台的加权计费不能直接等同原始 token 数。

数据来源
Codex 桌面与 CLI：~/.codex/sessions 与 archived_sessions 的 token_usage_record；以 response_id 去重，兼容旧版累计计数。
ZCode：~/.zcode/cli/db/db.sqlite 的 model_usage，以只读方式选择数值用量字段，包含实际产生用量的标题、压缩、子代理及重试请求。
pi + GLM：~/.pi/agent/sessions 的 assistant message、独立 usage 和带 usage 的压缩记录，仅纳入 GLM/智谱来源。
Kimi 桌面与 CLI：~/.kimi-code/sessions 下各 agent 的 wire.jsonl，仅统计 usage.record，不重复计算镜像状态或上下文事件。
Kimi 桌面和 CLI 共用记录，当前版本将两者合并显示，不假装能准确区分来源。

覆盖范围
仅统计本机保留、可读取并且带真实用量字段的记录。普通 ChatGPT 网页/桌面聊天、其他设备、被删除的历史记录，以及未记录用量的请求不在覆盖范围内。
某来源无记录时显示「暂无记录」；无法连接或格式不支持时显示对应状态。
应用退出后不能轮询额度，但本地客户端继续保存的记录会在下次启动时补入。
日界线使用系统当前时区，界面显示实际使用的时区。

本机存储
~/Library/Application Support/QuotaBar/quotas.json：最近一次额度数值。
~/Library/Application Support/QuotaBar/daily-usage.json：最近 30 天的分日数值汇总。
不保存对话正文。实时日志解析缓存只存在内存中。

构建
需要 macOS 13 或更高版本及 Apple Command Line Tools / Xcode。
在终端进入本源码目录，运行 bash build.sh；输出的 app 位于源码目录内的 dist 文件夹。
该版本使用本机构建签名，适合本地运行；尚未使用 Apple Developer 分发签名或公证。

验证命令
「额度看板.app/Contents/MacOS/QuotaBar --self-test」运行口径与解析测试。
「额度看板.app/Contents/MacOS/QuotaBar --check」只读检查当前三家额度和每日用量，输出不含凭据的 JSON。
「额度看板.app/Contents/MacOS/QuotaBar --usage-only」只读取本机用量，不联网查询额度。

更新适配
Codex、ZCode、pi 与 Kimi 的日志结构可能随版本变化。未识别的字段不会被当作零余额；应更新对应适配器后再纳入。
